🤖 AI 趋势洞察

🔥 值得关注

• Agent 37 Cloud — 把"给客户部署AI代理"从运维苦活变成一次API调用，定价低至$3.44/月，是典型的"卖铲子"生意。

• Atomic Mail Agentic — 用JMAP标准协议解决AI代理收发邮件的可靠性痛点，proof-of-work注册30秒搞定，思路极简。

• Backgrind — 把AI代理从终端解放到悬浮窗，颠覆了"agent只能在IDE里跑"的固有认知。

• Notchkin — 把MacBook刘海这个"废空间"变成高频笔记入口，创意十足且话题性强。

• Plansera AI — 用AI把$2000的签证文书服务压到$100/30分钟，垂直领域降维打击的典范。

📈 趋势信号

• AI代理从"对话工具"转向"需要持久身份和基础设施"的阶段，托管服务（Agent 37、Atomic Mail）开始成批出现。

• 桌面端AI代理体验竞争加剧，悬浮窗、刘海栏等系统级UI创新成为差异化切入点。

• MCP协议持续渗透传统SaaS（备份、邮件），"用聊天管理一切"成为开发者工具标配。

• 垂直专业场景（签证、房产投资）的AI应用开始以"平价替代高价人工服务"模式收割市场。

⚔️ 竞品对照

• Agent 37 Cloud vs Modal/Replicate — 专注持久化agent生命周期管理而非通用GPU跑批，按agent计费更贴合垂直SaaS。

• Cloudback MCP Server vs Backblaze B2 — 从存储层上移到"聊天即管理"的备份策略层，MCP是最大差异化。

• oioi vs Raycast/Paste — 免费开源+三平台支持+液态玻璃UI，以设计感和零成本抢夺剪贴板市场。

• Backgrind vs Claude Code/Cursor — 不替代工具而是做"悬浮层"，让agent在任意应用上工作，定位互补而非对抗。

🛠 Builder 启示

• 别做通用agent，做"特定场景+托管交付"（如签证、备份、邮件），按结果收费更容易起量。
