📈 趋势信号

• MCP协议持续爆发，今日Top 15中至少5款产品原生集成MCP，已成AI工具标配。

• "AI代理替你干活"从通用助手转向垂直场景代理（简历、编码、UX研究），自动化粒度更细。

• 开发者工具全面拥抱"让AI理解我的上下文"叙事，从代码库打包到数据源聚合都在消除AI使用摩擦。

• 数据可视化和分析正从"看板工具"演进为"自然语言问答即得答案"的对话式体验。

⚔️ 竞品对照

• Rixx vs Perplexity — 主打可验证引用和研究整理，而非单一搜索框。

• own.page vs Linktree — 用bento布局和流量分析把链接页升级为轻量个人网站。

• Tiny CV vs 传统简历工具 — 专为AI代理设计，支持X402和MPP免人工操作。

• Pi Coding Agent vs Claude Code — 以极简可扩展为核心理念，通过npm包共享定制工作流。

• LLMTest vs OpenRouter — 在路由基础上增加智能模型选择和自动故障回退。
