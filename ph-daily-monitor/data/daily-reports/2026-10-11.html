🤖 AI 趋势洞察

🔥 值得关注

• Ghost Core — 硬件+纯本地 AI，隐私赛道里少见的软硬一体打法。

• OpenScreen 2 — MIT 开源 + MCP 剪辑，直接威胁 Loom/Screen Studio 的付费墙。

• Edgee Mod for Claude Code — 模型路由层切入终端，是"套娃"生意里最聪明的一层。

• Agibot — 常驻后台 + 自带 Key 免费，Mac 代理赛道又添一员。

• HireKey — 大厂招聘官经验做成 AI 语音教练，差异化够硬。

📈 趋势信号

• 本地优先（local-first）成显学：Ghost Core、FocusWrite、SimpleSpread 都在卖隐私与速度。

• MCP 成基础设施标配：OpenScreen、kōdlo、Edgee 均以 MCP 作为扩展入口。

• 语音成为新交互层：Foley、HireKey、Tori 都把语音当作核心输入或输出。

• 开源 + 免费 + 自带 Key 的"反订阅"模式在榜单中反复出现。

⚔️ 竞品对照

• OpenScreen 2 vs Loom — 免费开源无水印，还多了 MCP 让 AI 代剪。

• SimpleSpread vs Numbers/Excel — 原生 Swift 秒开，砍掉一切冗余功能。

• Ayven vs Linear/Asana — 不等人填表，AI 主动拆活、催办、改排期。

• MePersona vs Hootsuite — 不做发布排期，只做"像你本人"的回复草稿。

• Foley vs Todoist — 语音捕获 + 不确定就追问，而非让你手填字段。

🛠 Builder 启示

• 把 MCP 当插件系统来做，能低成本接入 Claude/ChatGPT 生态换分发。

• "自带 API Key + 免费"是当下获客利器，但要想清楚 Pro 层卖什么。

• 垂直场景 + 专家经验（如 HireKey 的招聘官背景）比通用 AI 工具更容易上榜。

• 本地优先不只是隐私卖点，更是"秒开"体验差异化的技术护城河。
