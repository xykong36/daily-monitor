• Willow Frontier Pro — 免费轻量版+付费Pro版的双模型分层策略，直接对标Whisper生态的性价比打法。

• Bono AI — "口述即发布"把内容生产压缩到单一动作，对个人品牌创作者极具吸引力。

📈 趋势信号

• AI Agent 正在从"对话工具"演化为"执行体"，MCP 协议成为连接 AI 与外部世界（交易、硬件、API）的事实标准。

• 语音交互全面崛起：听写、口述生成内容、语音Agent 在本日 Top 15 中占据三席。

• 开发者工具转向"为 Agent 设计"——agents-cli、ExploreYC、Link Preview API 都在为 AI 代理提供数据与部署能力。

• 桌面端多账号隔离与自动化成为生产力新战场，Orbit 与 PopTask 均走买断制/免费起手的轻量路线。

⚔️ 竞品对照

• ExploreYC vs Crunchbase API — 免费开源+覆盖YC与a16z双源，对独立开发者零成本上手。

• Willow Frontier Pro vs Whisper/OpenAI STT — 主打"写作级润色"而非纯转写，且免费Mini版降低试用门槛。

• IvyForms vs Gravity Forms/WPForms — 强调提交后数据驱动的"工作流"而非单纯收集，内置条件逻辑与多工具连接。

• Orbit for Mac vs Shift/多浏览器配置 — 原生Swift仅12MB且买断$19，比Electron套壳竞品更轻更快。
