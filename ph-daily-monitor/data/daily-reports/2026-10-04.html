🤖 AI 趋势洞察

🔥 值得关注

• CoreSpeed：把 MCP 从单个工具升级成 Agent 的"操作系统"，含凭证托管、预算和审批，卡位精准。

• opensend.cc：明确对标 Resend，且只需改两行代码迁移，开源自托管戳中开发者数据主权焦虑。

• Octri.dev：SDK 自带生产环境错误回传，让 API 提供方在用户报 bug 前就发现问题，是真正的差异化。

• Thinking Orbs：Agent 状态可视化正在成为新的 UI 基础设施，小切口但会被大量复用。

• Sente：语音双向 + 404 模型聚合 + MIT 开源，日本团队做开发者工具值得留意。

📈 趋势信号

• MCP 已成默认分发渠道：今天至少 4 个产品（CoreSpeed、DocsAlot、Octri、Sente）把 MCP 作为核心卖点而非附加功能。

• "Agent 就绪"取代"人类可读"成为文档/API 的新标准，Blume 2.0 和 Octri 都在强调 agent-ready。

• 开源自托管回潮：opensend.cc、Blume、Sente 均以开源 + 自有数据/服务器对抗 SaaS 锁定。

• 基础设施层产品密集上榜（MCP、SDK、邮件、组件库），说明 AI 应用层正在沉淀工具链。

⚔️ 竞品对照

• opensend.cc vs Resend — 同为开发者邮件 API，但开源自托管且零按封计费，主打数据与发信信誉自主。

• Blume 2.0 vs Docusaurus — 都是 Markdown 文档框架，Blume 用零配置和 AI 可读性换取更快上手。

• Sellio vs Intercom — 同样做多渠道路由客服，Sellio 以 AI Agent 训练自有文档 + 共享收件箱做轻量替代。

• Smooth Recorder vs Screen Studio — 同为 Mac 美化录屏，Smooth Recorder 把"停止即剪辑"做成零后期流程。

• LaunchReel vs 传统视频剪辑工具 — 把视频当代码从 repo 生成，省去手动剪辑，但依赖 Claude Code 生态。

🛠 Builder 启示

• 如果你的产品能被 Agent 调用，今天就该发一个 MCP server——它正在替代传统 API 文档成为发现入口。

• 开源 + 自托管是对抗 Resend、Intercom 这类成熟 SaaS 的最有效切口，迁移成本要压到"改两行"。

• 别只做人类可读的文档，同时输出 agent-ready 格式（结构化、可解析），会吃到下一波流量。

• 小切口 UI 组件（如 Agent 状态动效）也能单独上榜，先把一个状态做到极致比做全套更容易被记住。
