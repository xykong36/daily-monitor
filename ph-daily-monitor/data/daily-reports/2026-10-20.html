🤖 AI 趋势洞察

🔥 值得关注

• /dev/null — 48 小时直播共建 + 大厂大佬站台，本身就是最好的增长案例。

• Harness² — Google Research 的递归 Agent 框架，指向 Agent 自我改进的下一个范式。

• Inflight — 用 MCP 把人类反馈直连编码 Agent，卡在 AI 开发工作流的关键缺口。

• ESP-Mosaico — 把 Agent 从软件推向物理硬件，硬件+AI 交叉点少见。

• Tiny Little Office — URL 即文档、零服务器零账号，隐私极简主义的漂亮解法。

📈 趋势信号

• Agent 基础设施集中爆发：支付、模型、反馈、文档四层今天同时上榜。

• 编码 Agent 生态成新入口，多家产品用"粘贴一句话完成配置"做 onboarding。

• Agent 正从软件走向硬件与物理世界（ESP-Mosaico、Asimov 1）。

• 开源与隐私叙事回归：MIT、无后端、无遥测成为卖点标签。

⚔️ 竞品对照

• Composio Instant vs Zapier/MCP 工具市场 — 免订阅按需付费，Agent 自助接入门槛更低。

• Exa 3.0 vs Tavily/Brave Search API — Dynamic Highlights 省 95% token，直击 Agent 成本痛点。

• ToDo.is vs Siri/常规 AI 助手 — 常驻沙箱 + 全渠道回传 + 付费前确认，更接近"代劳"。

• Kling 4.0 vs Runway/Sora — 先锁关键帧与参考资产，主打可控而非抽卡。

• reception vs Intercom/HelpScout — 原生 iOS SDK + 聊天内推付费墙，直接绑营收。

🛠 Builder 启示

• 把产品做成"一句话粘进编码 Agent 即可用"，是当下最低摩擦的获客路径。

• Agent 时代的机会在基础设施缝隙：支付、记忆、反馈、成本优化，而非再做通用助手。

• 开源 + 无遥测 + 本地存储，正在成为小团队对抗大厂的信任杠杆。

• 公开构建（直播、开源 PR）本身就是分发，/dev/null 证明了过程即营销。
