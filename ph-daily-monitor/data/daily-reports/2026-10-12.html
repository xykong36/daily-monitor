🤖 AI 趋势洞察

🔥 值得关注

• Google EmbeddingGemma 2 — 740M 参数塞进端侧还统一五种模态，Apache 2.0 意味着检索类产品的默认底座要换血。

• guilds.run — 多 Agent 最大的痛点是黑箱，可自托管 + 全链路可调试正好戳中。

• Manifold MCP — 把分散的营销数据源收成一个 MCP 入口，是"Agent 时代的营销 API"雏形。

• Kudos 3.0 — 不画图表、直接动手省钱，AI 从"看板"走向"替你执行"的典型样本。

• ExcaliClaw — 给 Excalidraw 类工具接上 MCP，小而准的切口，免费额度也够狠。

📈 趋势信号

• MCP 已成标配接口层，今天至少有 Manifold、Hexis、ExcaliClaw 三家把它当核心卖点。

• "可审查 / 可自托管" 取代 "最聪明"，成为 Agent 产品的新信任货币。

• 端侧小模型继续下探，EmbeddingGemma 2 用 567MB 内存跑全模态，本地 RAG 门槛再降。

• 从"给你看数据"转向"替你完成任务"：Kudos 打电话砍价、SquadRoom 交付成品，AI 开始承担结果责任。

⚔️ 竞品对照

• Base Code vs Lovable/Bolt — 不新建项目而是直接改你现有代码库并走 PR，切中团队协作而非原型玩具。

• Dropstone CLI vs Claude Code/Cursor — 差异在"纠正一次跨会话记住"的持久学习，而非每次重讲上下文。

• Scrape Anything vs Firecrawl — 同为托管抓取 API，但直接返回 Markdown/截图/结构化多格式，更贴 Agent 消费。

• Kudos 3.0 vs Rocket Money — 后者靠人工谈判，Kudos 用 AI 自动执行并保留 100% 节省，模式更轻。

• Ancher 2.0 vs Notion AI/Readwise — 不做文件夹整理，直接产出可交付的简报与内容，定位从"存"转向"出"。

🛠 Builder 启示

• 今天上榜产品一半以上在讲"可调试、可自托管、可审查"，做 Agent 工具时把透明度当功能卖点而非负担。

• MCP 接入成本已极低，任何有数据的产品都该先出一个 MCP server 蹭分发。

• 端侧嵌入模型免费开源，本地优先的检索/隐私类小工具现在是最低成本的差异化切口。

• 别再只做仪表盘，把最后一公里的"执行"包进来（打电话、发消息、开 PR）才是今年的溢价点。
