🤖 AI 趋势洞察

🔥 值得关注

• AgentKit by Scalekit — 把 Agent 鉴权与工具接入这块最脏的活做成网关，是典型的“卖铲子”高价值层。

• MachineMail — 给 Agent 配真实邮箱并做信任校验，切中 Agent 通信基础设施的空白。

• Wavefunction — 逆“超级 App”潮流的极简开源路线，自带模型选择与隔离桌面。

• Flockbay — 产物仍是标准 Godot 工程，不锁定格式，BYO 模型设计很讨喜。

• Testifly — “零提示词零维护”正好击中小团队没人写测试的痛点。

📈 趋势信号

• 今天榜单几乎被 Agent 基础设施承包：网关、邮箱、测试、终端，全是“给 Agent 用的工具”。

• MCP 正成为事实标准，AgentKit、MachineMail、Flockbay 都把它当第一接口。

• 一大波产品主打“零提示词/零维护”，竞争点从模型能力转向省心程度。

• 编码 Agent 进入编排层竞争：多 Agent 并行、独立 worktree、Windows 原生补位。

⚔️ 竞品对照

• AgentKit by Scalekit vs Zapier/Merge — 差异是“以用户身份、按授权范围执行”，而非固定工作流。

• Testifly vs Playwright/Mabl — 免写脚本且自愈，失败附视频解释。

• Prism vs Onshape/Fusion — 把 CAD 与物理求解交给 Agent 串联，定位“硬件版 Cursor”。

• nana vs tmux/Conductor — Windows 原生 + 每 Agent 独立 worktree + 状态可视化。

• Wavefunction vs Cursor/Claude Code — 反超级 App，开源、极简、可换任意模型。

🛠 Builder 启示

• 别再做通用 Agent，去做 Agent 的“水电煤”：鉴权、邮箱、测试、日志这类刚需层更容易被采用。

• 第一天就接 MCP 并给免费额度，能直接吃到 Agent 生态的分发红利。

• “零配置 + 自带模型/密钥”是当下最稳的定价与信任组合，降低试用摩擦。

• 把安全护栏（作用域、审计日志、隔离环境）当卖点而非成本，企业客户为此付费。
