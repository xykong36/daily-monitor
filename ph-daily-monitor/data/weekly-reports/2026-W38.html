⚔️ 竞品对照

• **CREEM 2.0 vs Stripe/Paddle**：不拼支付通道本身，而是把 MoR（记录商户）、税务、联盟分销和 AI 产品增长工具链整合为一体化后台，对独立开发者更友好。

• **Naoma AI Demo Agent V2 vs Chili Piper/Calendly**：不止于排期，而是用 AI Agent 主动识别网站访客意图并完成资格预审与预约，把“线索转化”从被动表单变成主动对话。

• **Kilo Code 移动端 vs GitHub Mobile/Cursor**：GitHub Mobile 侧重查看与轻量操作，Kilo Code 直接让手机成为编码 Agent 的遥控器，填补了“离开电脑仍能推进开发”的空白。

• **Slashy Assistant vs Superhuman/Gemini in Gmail**：不试图替代邮件客户端，而是以独立 AI 助手身份托管整个邮件处理流程，赌的是用户愿意把收件箱交给 Agent 而非自己操作。
