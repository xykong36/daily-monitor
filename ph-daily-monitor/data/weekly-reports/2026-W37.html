• **Mastra Factory** 以 425 票登顶，主打"从 issue 到生产全由 agent 跑通"，把 AI 编码从"辅助写代码"推进到"接管完整交付流程"，是本周最具野心的产品定义。

• **Switch** 把任意 AI agent 接入 Slack、Teams、Discord，切中了企业"agent 散落各处、无法统一调度"的真实痛点，开放协议 + 即时通讯入口的组合极具网络效应潜力。

• **Harden** 为 AI coding agent 加装安全层，在 agent 大规模写入代码库的当下，这是被严重低估但迟早爆发的刚需赛道。

• **Raycast 2.0** 作为成熟产品的大版本更新仍拿到 280 票，说明 Mac 效率工具的用户忠诚度极高，也侧面印证"AI 原生重构老工具"是一条稳妥路径。

📈 趋势信号

• **AI 品类绝对统治**：67 个产品、8990 票，占 Top 10 分类总票数的近半，且几乎渗透进每一个垂直场景（销售、客服、设计、笔记）。

• **"Agent 基础设施"成为新战场**：Mastra Factory、Harden、AI Observability、Cline Desktop 集中出现，市场焦点正从"造 agent"转向"管 agent、护 agent、观测 agent"。

• **开发者工具与开源深度绑定**：36 个 DevTools 产品中大量带 Open Source / GitHub 标签，开源已成为开发者产品获取早期信任和流量的默认策略。

• **销售/营销 AI 开始拼"结果交付"**：Anysite、Widgo、Youkti、Wisry 不再卖工具，而是直接承诺"找到买家""克隆爆款广告"，AI 正从 copilot 变成 outcome-as-a-service。

⚔️ 竞品对照

• **Switch vs 各家 agent 自带集成**：传统方案是每个 agent 各自对接 IM，Switch 用"任意 agent → 任意 IM"的中立层思路，创新点在于解耦与统一入口。

• **Harden vs 传统 SAST/代码扫描**：老牌安全工具面向人类提交的代码，Harden 专为 agent 高频、批量写入的场景设计，把安全左移到了 agent 运行时。

• **Cline Desktop App vs Cursor / Copilot**：Cursor 绑定闭源模型，Cline 主打开源应用 + 开放权重模型，抢的是"数据主权敏感"的开发者心智。

• **Cortex vs 传统 API 文档工具**：ReadMe、Swagger 只生成文档，Cortex 一键产出 docs + SDK + MCP server，直接对接 agent 消费场景，是 API 工具的范式升级。

🛠 Builder 启示

• **别再做"AI 写代码"，去做"AI 干完活"**：Mastra Factory 的高票说明，能交付端到端结果的产品比单点辅助工具更受追捧，把 agent 串成完整工作流是差异化关键。

• **给 agent 生态做"配套"比做"主角"更稳**：安全（Harden）、观测（OpenObserve）、上下文库（Resurf）都是 agent 爆发后的衍生刚需，竞争小、付费意愿明确。

• **开源是开发者产品的入场券而非终点**：本周高票 DevTools 几乎都开源，但真正拉开差距的是能否把开源流量转化为 MCP/API 等可持续集成点。

• **垂直场景 + 结果承诺 = 更快的付费转化**：销售、营销类产品直接承诺"找到买家""复制爆款"，对独立开发者而言，与其做通用工具，不如在细分场景里把 ROI 讲清楚。
