🔥 值得关注

• **S.Space（#3）** 试图把"你的团队 + 所有人的 AI agent"塞进同一个协作空间，这是本周对"多 agent 协作"最直白的产品化尝试，值得看它怎么解决权限与上下文隔离。

• **TestSprite 4.0（#5）** 直击"改一处坏一处"的回归测试痛点，把 AI agent 定位成持续验证者而非一次性代码生成器，切中了开发者对 AI 写码最大的不信任。

• **Verse Engine by Ctruh（#10）** 把 Blender/Unity/Unreal 场景一键变成可分享的 3D 链接，绕开游戏引擎分发门槛，在 3D 内容"链接化"上是个轻巧的切口。

• **Yoroll（#11）** 无引擎做可玩故事，把"互动叙事"从游戏开发里解耦出来，可能吸引一批被引擎复杂性挡在门外的创作者。

📈 趋势信号

• **AI 标签几乎吞噬全场**：81 个产品、10937 票，占 Top 10 分类票数六成以上，"AI + 某个垂直工作流"已成默认叙事，纯工具型产品很难单独出圈。

• **Agent 基础设施化**：Boost.space AgentOS、S.Space、Appxiom、Toone 都在做 agent 的"操作系统/上下文层/编排层"，说明竞争正从"做一个 agent"转向"管一堆 agent"。

• **开发者工具是第二大票仓**（45 个产品、6028 票），且高度集中在测试、部署、上下文管理，AI 编码的"周边配套"比编码本身更热。

• **SEO 正在被"AI 搜索"重写**：RankSpot、Rankhog、EkLine 三个 SEO 产品同周上榜，且都强调 AI Search / Reddit / API 公司，传统 SEO 工具品类在被重新定义。

⚔️ 竞品对照

• **Bluedot Phone Calls（#6）** 对比 Otter/Fireflies 这类会议记录工具，创新点是把 AI 笔记从视频会议延伸到电话通话，补上了销售、客服场景的空白。

• **Zoom Slides（#13）** 对比 Gamma、Tome，不抢"从零生成演示"的赛道，而是把已有会议内容转成幻灯片，走的是"会后沉淀"而非"会前创作"。

• **OpenBot（#19）** 对标 Grok Bot 主打自托管、可定制、任意技术栈，用开源和部署自由对抗闭源 SaaS 的锁定，是典型的"开放替代"打法。

• **Netlify Server（#14）** 对比 Vercel 的 serverless 生态，明确支持 WebSocket、多人应用和长时运行 agent，瞄准的是 agent 时代对"长连接 + 常驻进程"的新需求。

🛠 Builder 启示

• **别再做通用 AI 助手**：本周上榜产品几乎都绑定一个具体工作流（电话、会议、Reddit 获客、回归测试），垂直切口比能力广度更能拿票。

• **"管 agent"比"做 agent"更有机会**：AgentOS、上下文层、编排工具密集出现，独立开发者可从 agent 的可观测性、权限、成本控制等缝隙切入。

• **开发者工具要押"AI 写码的副作用"**：测试、bug 检测、上下文供给是刚需，且付费意愿强，比再做一个代码补全更可持续。

• **SEO/营销类产品要重写关键词**：把定位从"Google 排名"换成"AI 搜索可见性""Reddit 获客""API 公司 SEO"，同一需求在新叙事下更容易被看见。
