• **Databox CLI**（#8，267票）和 **Filament by Galaxy**（#9，258票）双双把分析/数据能力搬进终端，说明"给 agent 用的 CLI 界面"正在成为独立产品形态。

📈 趋势信号

• AI 类产品 75 个、近万票，几乎占据榜单半壁江山，且已从"套壳聊天"下沉到具体岗位（销售、招聘、会计、广告投放），垂直 agent 是本周绝对主线。

• Developer Tools（42个）与 GitHub（26个）、Open Source（18个）高度重叠，开源 + 开发者工具 + AI 的三重标签组合成为上榜标配。

• 营销侧出现明显分工：Alsona 抓购买信号、Maxma 优化投放、ScroogeFrog 防广告欺诈，AI 正在把营销预算的每一环都产品化。

• "Agent 的基础设施"集中冒头——模拟环境（Plurai）、图数据库（Omnigraph）、安全模型（Arcjet）、终端分析（Databox/Filament），卖铲子的比淘金的更密集。

🛠 Builder 启示

• 本周高票产品几乎都带 "AI + 具体场景 + 明确 ROI" 三件套，独立开发者应避免泛化助手，锁定一个可量化收益的窄场景。

• 开源 + GitHub 是低成本获取开发者信任的杠杆，18 个开源产品合计 2343 票，说明"可自托管、数据归自己"本身就是卖点。

• 给 agent 做配套基础设施（评估、安全、数据层、CLI）竞争尚不拥挤，比直接做 agent 应用更容易建立壁垒。

• 票数集中在 200–370 区间、Top20 差距不大，说明本周没有绝对爆款，产品叙事和首发渠道运营的重要性不亚于功能本身。
